# Progression

These are rules for leveling up and improving characters.

## When to level up?

Any time you expload twice when making a skill check, you level up.
Additionally, any story beats of significance can result in a level up at the game masters discression.

## Benifits

When leveling up you may either

1. gain a new technique
2. upgrade an existing technique

after wich any applicable skill improvements are applied

see [technique dice](#technique-dice) for more details.

### Skill Improvement

Every third level up you gain a new skill or improve a not an already improved skill of your
choosing in addition to the standard level rewards.

If you do not already have one (or your current skill dice is full), you get a new character skill dice. Then add two
faces of the given skill to the new dice. You may only improve a given skill at most once.

The technique you aquire during this level up can be in the new skill you get if you choose to generate a new skill
this round.


## Technique Dice

Technique dice represent specialized techniques within skills that your character can use. Think of them
similar to abilities. They should be more specific than skills. For example the skill "air bending" might
have the technique "wind slash" that does a very specific thing under the given skill.

Technique dice have four faces on them representing the technique in question.

Unlike with character dice, you do not include technique dice in every roll. Instead include a technique dice
only when it applies to the roll you are doing (e.g. you are using that technique). Only one technique may
be applied at once to any given roll.

Techniques can be used at most once per short rest.

Technique dice may be used as the dice for the help action.

> TIP:
>
> Game Masters can and should (sometimes) use the remaining two faces
> for special triggers per technique that provide some unique
> advantage when hit. As allways do what you think is fun and
> be creative!

### Upgrading Technique Dice

Techniques can be improved and upgraded.

To upgrade a technique dice select one of the following for it:

#### Per Scene Use

Mark one of the blank faces on the dice to indicate that this dice is a per scene technique. It
now can be used once per scene instead of once per short rest.

#### Cooldown Faces

Mark two of the success faces on the dice as cooldown faces. The dice can now be re-used until a
cooldown face is hit. Once a cooldown is hit the technique may not be used again until a short rest.
Hitting a cooldown still counts for your success total (assuming the technique is applicable).


### Game Master Techniques

As with character dice game masters should have a single generic technique dice that can be used
on any character that comes up during the course of play.

For known NPC's we recommend creating technique dice with unique abilities, dice that cause some effect to happen
when a specific face of the dice is rolled, be creative with it and have fun!
